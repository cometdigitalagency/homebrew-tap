# Comet Homebrew Tap

Homebrew formulae for Comet tools.

## Install

```bash
brew install cometdigitalagency/tap/cometai
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `cometai` | Monitor Claude AI token usage — burn rate, cost, and remaining quota |

## Update

```bash
brew upgrade cometai
```
